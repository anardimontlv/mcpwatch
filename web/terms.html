What the service is

mcpwatch publishes automated security checks of Model Context Protocol (MCP) servers and helps you detect when the tools you rely on change. Package checks are static: we never run third-party code. For remote servers we send the standard MCP handshake and a tool-listing request to the public endpoint the publisher listed (details); we never call a tool, never send credentials and stop if a server requires authentication. Grades and findings are automated opinions based on the facts shown on each page and on our published methodology. They are not audits, penetration tests, accusations of wrongdoing or guarantees of safety. You remain responsible for your own security decisions.
