        Connect CI

        Create a report key, save it as the MCPWATCH_REPORT_KEY secret in each repo (or your GitHub organization), and add this step after checkout:

        - run: pipx run --spec mcpwatch-io==0.3.0 mcpwatch report .mcp.json
  env:
    MCPWATCH_REPORT_KEY: ${{ secrets.MCPWATCH_REPORT_KEY }}
    GITHUB_REPOSITORY: ${{ github.repository }}
