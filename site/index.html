Know when the tools your AI agents trust change.

MCP servers can rewrite a tool's instructions after you approve it: a rug pull. mcpwatch:

  • Spots changes: fingerprints every server in the official MCP registry daily.
  • Grades risk: leaked secrets, plain HTTP, no login, poisoned descriptions.
  • Blocks in CI: fails the build when a tool you pinned changes.

Quickstart

Zero dependencies, Python 3.10+. Works with Claude Desktop, Claude Code (.mcp.json), Cursor and VS Code configs.

pipx install mcpwatch-io

  1. Scan

    Flag leaked secrets, unpinned packages, plain HTTP and root filesystem access.

    mcpwatch-scan ~/.cursor/mcp.json

  2. Lock

    Pin the exact tools your servers expose today. Commit mcpwatch.lock.

    mcpwatch lock .mcp.json

  3. Check

    Fail CI when any pinned tool changes: exit 1 on drift. Add --live to see the exact sentence that changed.

    mcpwatch check .mcp.json

  4. Guard

    Block changed tools at runtime: your agent only sees the tools you approved.

    mcpwatch guard --name gh -- <server cmd>
